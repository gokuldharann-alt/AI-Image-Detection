EfficientNet-B0 brain @384px

5.3M params, 1 binary logit + sigmoid = P(FAKE). Pre-trained on ImageNet, fine-tuned on CIFAKE, then adapted to HQ (COCO real photos vs MidJourney / NanoBanana / art fakes, 512px canonical, REAL==FAKE).

⚡

Sub-200 ms pipeline

Resize→441 + CenterCrop→384 + ImageNet normalize → channels_last → ONNX Runtime on CPU / FP16 on CUDA. Model loads once at startup. Set TORCH_WEIGHTS/ONNX_WEIGHTS to hq_*.pt/onnx.

🔬

Glass-box + continual learning

Every request streams decode / preprocess / forward / postprocess timings, logit, throughput + last-conv sparsity. Wrong? Hit Actually REAL/FAKE → learn_feedback.py appends to the same hq_*.pt.
